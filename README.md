# PackMate

PackMate — це desktop-застосунок на Qt Widgets для ведення локального списку речей у подорож. Користувач створює подорож, додає речі, розділяє їх за категоріями, позначає зібрані позиції та бачить прогрес пакування.

## Цільовий користувач

Застосунок орієнтований на користувача, який хоче швидко підготувати простий список речей перед поїздкою без акаунтів, інтернету та складних сервісів.

## MVP-функції

- створення подорожі;
- редагування подорожі;
- перегляд головної сторінки з інформацією про подорож;
- додавання речей до списку;
- редагування речей;
- видалення речей;
- позначення речі як зібраної або незібраної;
- фільтр речей за категорією;
- підрахунок прогресу пакування;
- збереження та завантаження даних із JSON;
- екран “Про програму / Допомога”.

## Не входить у MVP

- акаунти користувачів;
- синхронізація між пристроями;
- онлайн-сервіси;
- погода;
- карти;
- авіаквитки;
- нагадування;
- складний календар;
- кілька активних подорожей з окремим перемикачем у UI.

## Архітектура

Проєкт має просту структуру, типову для навчального Qt Widgets застосунку.

- `MainWindow` відповідає за головне вікно, екрани, кнопки, таблицю, фільтри та основні дії користувача.
- `AddEditItemDialog` відповідає за форму додавання та редагування речі.
- `Models` містить структури даних, enum-и категорій/важливості та перетворення в JSON.
- `Storage` відповідає за читання та запис `packing_data.json`.

Окремого controller/service шару немає: більшість логіки MVP знаходиться в `MainWindow`.

## Модель даних

Основні сутності:

- `Trip`: `id`, `title`, `destination`, `startDate`, `endDate`, `createdAt`.
- `PackingItem`: `id`, `tripId`, `name`, `category`, `quantity`, `priority`, `isPacked`, `note`.
- `AppState`: `selectedTripId`, `selectedItemId`, `activeCategoryFilter`, `hasUnsavedChanges`.

Категорії речей:

- Documents
- Clothes
- Electronics
- Hygiene
- Medicine
- Other

## JSON-збереження

Дані зберігаються локально у файлі:

```text
data/packing_data.json
```

Файл створюється поруч із запущеним `.exe`, тобто в папці збірки під час запуску з Qt Creator. Якщо файл відсутній, програма вважає це першим запуском. Якщо JSON пошкоджений, програма показує попередження і залишається придатною до використання.

Приклад структури:

```json
{
  "trips": [],
  "items": [],
  "state": {
    "selectedTripId": "",
    "selectedItemId": "",
    "activeCategoryFilter": "Усі"
  }
}
```

## Збірка в Qt Creator

1. Відкрити Qt Creator.
2. Відкрити проєкт через `CMakeLists.txt`.
3. Обрати Desktop Qt kit з підтримкою Qt Widgets.
4. Запустити Configure Project.
5. Натиснути Build.

Також у проєкті є `PackMate.pro`, але основний варіант для збірки — CMake.

## Запуск

Після успішної збірки натиснути Run у Qt Creator. Дані будуть збережені у папці `data` поруч із виконуваним файлом у build-директорії.

## Ручне тестування

1. Запустити застосунок.
2. Перевірити, що без подорожі кнопки для списку речей і редагування подорожі недоступні.
3. Створити подорож із назвою, місцем призначення та датами.
4. Спробувати створити подорож без назви — має з’явитися попередження.
5. Спробувати дату початку пізніше дати завершення — має з’явитися попередження.
6. Відредагувати подорож і перевірити, що головна сторінка оновилась.
7. Відкрити список речей.
8. Додати кілька речей у різних категоріях.
9. Відредагувати річ.
10. Позначити річ як зібрану та незібрану.
11. Перевірити фільтр за категорією.
12. Видалити річ.
13. Перевірити прогрес на головній сторінці.
14. Натиснути “Зберегти”.
15. Перезапустити застосунок і перевірити, що дані завантажились.
16. Пошкодити `packing_data.json` і перевірити, що програма показує попередження, але не падає.

## Відомі обмеження

- Немає акаунтів і синхронізації.
- Немає окремого списку для перемикання між кількома подорожами.
- Дані зберігаються тільки локально у JSON.
- Немає автоматичних тестів.
- Нотатка речі зберігається, але не показується окремою колонкою в таблиці.
- Обробка помилок JSON базова і призначена для MVP.
