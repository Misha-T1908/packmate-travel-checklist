# PackMate

PackMate — це desktop-застосунок на Qt Widgets для створення локального списку речей у подорож.

Користувач створює подорож, редагує її дані, додає речі на кшталт “паспорт”, “зарядка”, “футболка”, “ліки”, позначає вже зібрані речі та бачить прогрес пакування.

## MVP

У проєкті реалізовано тільки базові можливості:

- створення подорожі;
- редагування подорожі;
- додавання речей до списку;
- редагування речей;
- видалення речей;
- позначення речі як зібраної або незібраної;
- фільтр за категорією;
- прогрес пакування;
- збереження та відновлення даних із JSON;
- екран “Про програму / Допомога”.

## Не входить у MVP

- акаунти;
- синхронізація;
- погода;
- карти;
- авіаквитки;
- онлайн-сервіси;
- нагадування;
- складний календар.

## Дані

Застосунок зберігає дані у файл:

```text
data/packing_data.json
```

Папка `data` створюється автоматично поруч із запущеною програмою.

## Демо-сценарій

1. Користувач відкриває PackMate.
2. На сторінці “Головна” натискає “Створити подорож”.
3. Вводить назву подорожі, місце призначення та дати.
4. За потреби натискає “Редагувати подорож” і змінює дані подорожі.
5. Натискає “Відкрити список речей”.
6. Додає кілька речей: паспорт, зарядку, футболку, ліки.
7. Для кожної речі вибирає категорію, кількість і важливість.
8. Позначає частину речей як зібрані.
9. Повертається на головну сторінку та бачить прогрес пакування.
10. Натискає “Зберегти”.
11. Після перезапуску програма відновлює подорож і список речей.

## Збірка

Відкрийте проєкт у Qt Creator через один із файлів:

- `CMakeLists.txt`
- `PackMate.pro`

Після цього оберіть Qt Widgets kit, зберіть і запустіть застосунок.
